# Khadim Hussain — Portfolio

Personal portfolio site for Khadim Hussain, Workshop, Fabrication & Erection Superintendent (oil & gas).

- Stack: React 19 + TypeScript + Vite, Tailwind CSS v4, GSAP, Lenis, lucide-react
- Content lives in `src/data/profile.json`; logos in `public/logos`, certificates in `public/certs`, site photos in `public/img/site`
- Four colour themes, switchable from the nav

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Pushing to `main` builds the site and publishes it to GitHub Pages (`.github/workflows/deploy.yml`).
